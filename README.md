# Cursed Expansion

Браузерная игра-менеджмент про оборону портала: захват клеток Вороного,
добыча ресурсов, набеги демонов и экзамен в виде босса.

## Запуск

Игра использует ES-модули, поэтому её нужно открывать **через локальный сервер**
— с `file://` браузер заблокирует загрузку модулей.

```powershell
cd F:\dark_demiurge
python -m http.server 8123
```

Затем открыть <http://127.0.0.1:8123/dark_demiurge.html>.

Нужен интернет для CDN-библиотеки `d3-delaunay` (диаграмма Вороного).
Если она не загрузилась, на экране появится соответствующее сообщение.

### При разработке

Обычный `http.server` не запрещает кэширование, и браузер может отдать старые
модули — правка в `js/` не видна, и это выглядит как «баг не починился».
Для разработки удобнее сервер без кэша:

```powershell
python server_nocache.py     # http://127.0.0.1:8124
```

## Структура

```
dark_demiurge.html      разметка, стили, подключение модулей
js/
  config.js             ВСЕ игровые числа и таблицы (биомы, враги, постройки)
  state.js              изменяемое состояние (объект S) и производные величины
  world.js              геометрия: точки Вороного, рёбра, радиусы, кэши
  sprites.js            предрендер иконок в offscreen-канвасы
  logic.js              правила: захват, люди, постройки, враги, бой, босс, набег
  render.js             отрисовка мира
  ui.js                 HUD, панель ресурсов, попапы, легенда
  main.js               события ввода, цикл кадра, старт, консольные команды
дизайн документ.md      правила, баланс и план развития
```

Правило: любое число, на которое можно повлиять геймплеем, живёт в
`js/config.js`. В остальных файлах — только безразмерные технические константы.

## Консольные команды

Открыть DevTools (F12) → Console → `CE.help()`.
Нужны для проверки эндгейма без долгого набивания ресурсов руками.

```js
CE.all(150)      // поздняя партия: портал 30, 150 клеток, люди, ресурсы, монолит
CE.res(1000)     // +1000 к каждому ресурсу
CE.blood(5000)   // +5000 крови хаоса
CE.people(50)    // +50 людей в пул
CE.cap(120)      // принудительный лимит людей
CE.level(30)     // уровень портала (открывает биомы)
CE.claim(30)     // захватить 30 клеток
CE.monolith()    // поставить монолит с рабочим
CE.boss()        // вызвать босса вне набега
CE.raid()        // начать набег
CE.raidMult(20)  // изменить множитель спавна во время набега
CE.win()         // немедленная победа
CE.state()       // сводка состояния
CE.CONFIG        // все игровые константы
```
